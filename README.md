## Kaynaklar ve Teşekkür (Credits)

Bu proje geliştirilirken aşağıdaki açık kaynak verilerden ve kütüphanelerden yararlanılmıştır:

* **Türkiye İl Sınırları Verisi:** [tr-geojson](https://github.com/cihadturhan/tr-geojson) deposu için **Cihad Turhan**'a teşekkürler.
    * *Kullanılan Veri Seti:* `tr-cities-utf8.json`
* **Harita Verileri:** [OpenStreetMap](https://www.openstreetmap.org/copyright) katkı verenleri (ODbL Lisansı kapsamında).
* **Soru Havuzu:** [Elif KURNAZ](https://www.linkedin.com/in/elif-kurnaz-4b8bb1360?utm_source=share&utm_campaign=share_via&utm_content=profile&utm_medium=android_app) tarafından hazırlanmıştır.
* **Harita Motoru:** [Leaflet.js](https://leafletjs.com/)
* **Altlık Harita (Tiles):** Esri World Imagery
